# test 目录

斐波那契数列计算示例项目：计算第 n 项的值，输出时在数值末尾追加一个小爱心 ♥，
并把结果写入 `result.txt`。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `fibonacci.py` | 主脚本：计算斐波那契数列并写出结果 |
| `test_fibonacci.py` | 单元测试（`unittest`） |
| `result.txt` | 运行脚本后生成的结果文件（UTF-8） |

## 环境要求

- Python 3.7+（本机使用 `py` 启动器，版本 3.9.13）

## 使用方法

在项目根目录运行：

```bash
py test/fibonacci.py
```

脚本会随机挑选 3 个下标（默认范围 1–30），计算对应项并输出：

```
斐波那契数列计算结果
==============================
fibonacci(10) = 55 ♥
fibonacci(15) = 610 ♥
fibonacci(29) = 514229 ♥
```

结果同时写入 `test/result.txt`（UTF-8 编码，与脚本同目录）。

> 注意：Windows 控制台默认编码（如 cp1252）可能无法显示中文和 ♥，
> 终端里会看到 `?`，但文件内容是正确的。

## API 说明

```python
fibonacci(n)                    # 返回第 n 项，n >= 1，否则抛 ValueError
format_line(n)                  # 返回 "fibonacci(n) = <值> ♥"
pick_random_targets(count, low, high)  # 随机取不重复下标，升序返回
build_report(targets)           # 生成完整报告文本
```

约定：`F(1) = 1`，`F(2) = 1`，`F(n) = F(n-1) + F(n-2)`。
实现采用迭代方式，时间复杂度 O(n)、空间复杂度 O(1)，支持任意大整数。

## 运行测试

```bash
py -m unittest discover -s test -p "test_*.py" -v
```

当前共 11 个测试，覆盖数值正确性、递推关系、非法输入、大整数、
爱心后缀格式、随机取值和报告生成。
